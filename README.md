# AESR Project Page

Official project page for **Identity-Preserving Text-to-Video Generation via Agentic Enhancement and Semantic Repair**.

The page includes the paper, method overview, and four qualitative comparisons across the Seedance 2.0 baseline, official document-based playbook, Stage I agentic enhancement, and the full Stage I & II pipeline.

## Authors

Jiayi Gao, Changcheng Hua, Jiaqi Tang, Yuxin Peng, and Yang Liu  
Wangxuan Institute of Computer Technology, Peking University
